# Notice

`@debutify/liquidjs` is a fork of [LiquidJS](https://github.com/harttle/liquidjs) by Harttle and its contributors, used under the MIT licence in `LICENSE`.

Debutify maintains this fork to render Shopify themes outside Shopify. It adds opt-in engine options (`numberSemantics`, `rawTags`, `inlineErrors`) and, under `@debutify/liquidjs/shopify`, Shopify's platform tags, filters and theme runtime. With the default options it behaves exactly like the LiquidJS release named in `package.json` → `upstreamLiquidjs`.
